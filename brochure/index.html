Printing it

1

A4, landscape, double-sided

Scale 100%. Not “fit to page” — that shrinks the QR code and the margins with it.

2

Fold once down the middle

The front cover ends up on top, the prices on the back. It opens like a card.

3

If the inside is upside down

Reprint and switch the duplex setting between flip on long edge and flip on short edge. The inside of this file is pre-rotated, so long edge is the one to try first.

4

At a print shop

Hand them the PDF and ask for A4, 170–250gsm silk, double sided, full bleed, folded once to A5. They’ll sort the rest.

The code on the cover points at rahulkd.com and is set to the highest error correction, so it still scans with a thumbprint on it or a scuff across one corner. On a home printer you’ll get a thin white edge around the orange — it still works fine.
